# Learn Password

This project was developed completely by AI.

It was made with AI because of a lack of time and because I wanted to learn a new password NOW.

---

## Project Details

A modern single-page React app with two password fields:

- **Enter password**: original password input
- **Learn password (retype)**: training input to retype and match

Features:

- live strength meter
- live match feedback
- show/hide toggles on both fields
- copy password action
- reset form action

## Quick start

```bash
cd /home/pascal/Projects/learn-password
npm install
npm run dev
```

Open the local URL shown by Vite (usually `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview
```

## Project structure

- `index.html` – Vite entry HTML
- `src/main.jsx` – React bootstrap
- `src/App.jsx` – password learner UI logic
- `src/styles.css` – app styling
- `package.json` – scripts and dependencies
